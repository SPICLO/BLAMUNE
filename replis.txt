# Banque de repli hors ligne de BLAMUNE (français).
#
# Format : situation|variante1;;variante2;;variante3
#   - une situation par ligne ;
#   - une variante par « ;; », tirée au hasard (on évite les répétitions) ;
#   - ignorer les lignes commençant par « # ».
#
# Règle : BLAMUNE n'invente jamais un fait. Sur une question, il avoue
# qu'il ne sait pas et relance la conversation. C'est mieux que d'inventer.
#
# Situtations reconnues :
#   erreur_ia    l'IA est injoignable (quotas, coupure, clé absente)
#   question     l'utilisateur pose une question
#   generique    message quelconque sans situation reconnaissable
#   court        message de 1 à 3 mots
#   vide         message vide ou quasi vide
#   salut        bonjour / bonsoir / coucou
#   remerciement  merci
#   au_revoir    au revoir / à plus
#   question_bot qui es-tu / ton nom
#   blague       l'utilisateur rigole
#   tristeesse    le'utilisateur va mal
#   colere        le utilisateur est en colère
#   fatigue       l'utilisateur est crevé
#   complement   il complimente BLAMUNE
#   encouragement il cherche une motivaton
#   matin / apresmidi / soir / nuit   selon l'heure

Tu veux qu'on cherche ensemble ?;;Je préfère rester honnête plutôt que te sortir une bêtise : dis-moi ce que toi tu en penses
